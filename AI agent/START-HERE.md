## Today (about 45 minutes)

1. Install Python 3.12+ from python.org and **check Add to PATH** (see `01-hello-llm/README.md`).
2. Get an OpenAI API key and set a spend limit.
3. In `01-hello-llm`, create a venv, copy `.env.example` to `.env`, paste the key.
4. Run `python main.py --style tutor` and `python main.py --style poet`.
5. Run `python chat.py` and ask a follow-up question.
6. Rewrite the three definitions in `01-hello-llm/notes.md` in your own words.

When those six steps are done, say **continue** and we will build Stage B: extract JSON from messy text.
